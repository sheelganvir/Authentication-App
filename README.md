# 🛡️ AuthGuard System

**GitHub Repository**: [https://github.com/sheelganvir/Authentication-App](https://github.com/sheelganvir/Authentication-App)

## 📋 Project Overview

AuthGuard System is a secure authentication platform built using the **MERN stack** (MongoDB, Express.js, React.js, Node.js) with **JWT-based authentication**. The system is designed to provide secure login, validation, error handling, and seamless session persistence.

### 🔐 Key Features:
- **Secure Login System**: A secure login for 100+ users with validation and error handling.
- **Session Persistence**: Achieved 99.9% session persistence using JWT-based authentication and cookie storage in Express.js.
- **Responsive Design**: Optimized the web app for 95% of devices, boosting user engagement by 30%.
- **Cookie-based Authentication**: Utilized cookies for storing authentication tokens to enhance security.
- **Error Handling**: Implemented robust error handling and validation mechanisms for a smooth experience.

## 🛠️ Technologies Used
- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT (JSON Web Tokens)
- **Other**: HTML, CSS

## ⚙️ Installation

To get a local copy of the repository up and running, follow these simple steps.

### 1. Clone the repository:
```bash
git clone https://github.com/sheelganvir/Authentication-App.git
```
### 2. Install dependencies for both frontend and backend:
- Navigate to the backend folder:
```bash
cd Authentication-App/backend
npm install
```
- Navigate to the frontend folder:
```bash
cd Authentication-App/frontend
npm install
```
### 3. Set up environment variables:
Ensure to add the necessary environment variables (e.g., JWT secret, MongoDB URI, etc.) to the .env file in the backend folder.

### 4. Run the application:
- For the backend:
  ```bash
  cd Authentication-App/backend
  npm start
  ```
- For the frontend:
  ```bash
  cd Authentication-App/frontend
  npm start
  ```
## 🚀 Usage
- The app allows users to register and login securely using JWT-based authentication.
- Session persistence is maintained via cookies, ensuring users remain logged in even after a page refresh.
- Access the app at http://localhost:3000.
